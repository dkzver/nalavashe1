# Интеграция LAVA DASH с nalavashe-vl.ru

## Текущее состояние

Репозиторий `dkzver/nalavashe1` — отдельное Vite/Three.js приложение LAVA DASH. В нём нет исходников основного сайта ресторана, поэтому безопасная интеграция выполняется через публикацию собранной игры в отдельном URL-префиксе, а затем добавление ссылки на этот адрес в основной сайт.

## Рекомендуемый адрес

`https://nalavashe-vl.ru/game/`

## Сборка

Собирать игру с base path:

```bash
VITE_BASE_PATH=/game/ npm run build
```

На Windows PowerShell:

```powershell
$env:VITE_BASE_PATH="/game/"; npm run build
```

Содержимое каталога `dist/` публикуется так, чтобы `index.html` был доступен по `/game/`, а сгенерированные JS/CSS и `assets/` — по соответствующим относительным адресам внутри `/game/`.

## Изменение основного сайта

После публикации добавить обычную ссылку в меню/на главную страницу сайта:

```html
<a href="/game/">Играть в LAVA DASH</a>
```

Если сайт использует CMS, ссылку лучше добавить штатными средствами CMS. Не заменяйте корневой `index.html` основного сайта файлами игры.

## Серверная интеграция

На текущем этапе игра полностью клиентская. Рекорды хранятся в LocalStorage конкретного браузера. Проверка промо-наград не активна. Если появится система призов, результат забега должен проверяться сервером; клиентский счёт нельзя считать доверенным источником для начисления скидки или промокода.
