# LAVA DASH

LAVA DASH — браузерный 3D endless runner для ресторана «На LAVAше». Проект использует Vite, Three.js и WebGL. Основная сцена и игровой цикл реализованы на Three.js без 2D-заглушек.

## Запуск локально

Требуется Node.js 20.19+ или 22.12+ (актуальные требования Vite 8).

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию порт 3000).

## Production-сборка

```bash
npm ci
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Его можно разместить на любом статическом хостинге с поддержкой SPA/static fallback.

### Размещение в подпапке основного сайта

Для публикации игры по адресу `https://nalavashe-vl.ru/game/` задайте переменную окружения на этапе сборки:

```bash
VITE_BASE_PATH=/game/ npm run build
```

На Windows PowerShell:

```powershell
$env:VITE_BASE_PATH="/game/"; npm run build
```

Содержимое `dist/` нужно разместить в каталоге, который веб-сервер отдаёт по пути `/game/`. Внутренние ссылки на стили, скрипты и логотип используют относительные пути, чтобы сборка могла работать в подпапке.

Если игра публикуется в корне отдельного домена или поддомена, переменную `VITE_BASE_PATH` можно не задавать.

**Важно:** этот репозиторий содержит приложение LAVA DASH. Для добавления ссылки на игру в навигацию основного сайта нужно отдельно изменить репозиторий/админку самого сайта или конфигурацию веб-сервера. Не копируйте файлы игры поверх файлов основного сайта.

## Управление

- Влево / вправо: `A` / `D` или стрелки.
- Прыжок: `W`, `↑` или `Space`.
- Подкат: `S` или `↓`.
- Пауза: `Esc` или `P`.
- На телефоне: свайпы и сенсорные кнопки.

Повторное срабатывание удерживаемых клавиш отключено: одно нажатие соответствует одному действию. Клавиши управления не перехватываются, когда фокус находится в интерактивном элементе интерфейса.

## Структура

- `src/main.js` — инициализация приложения и обработка ошибок запуска.
- `src/game/Game.js` — игровой цикл, состояние, камера, скорость и столкновения.
- `src/game/Player.js` — процедурная 3D-модель шаурмы, физика и анимация.
- `src/game/World.js` — бесконечная городская улица, здания и декорации.
- `src/game/Obstacles.js` — пул препятствий и генерация волн.
- `src/game/Collectibles.js` — еда, бонусы и сбор предметов.
- `src/game/Collision.js` — AABB-столкновения.
- `src/game/Controls.js` — клавиатура, свайпы и мобильные кнопки.
- `src/game/Audio.js` — музыка и звуковые эффекты Web Audio.
- `src/game/UI.js` — меню, HUD, рекорды и экран результата.
- `src/style.css` — оформление интерфейса.

## Игровая логика и маркетинг

- Забег рассчитан примерно на 2–3 минуты с постепенным ростом скорости.
- Рекорд хранится локально в браузере.
- Кнопки заказа ведут на официальный сайт ресторана.
- Проверка промо-наград пока не подключена: `PromoService` возвращает `null`. Игра не показывает выдуманные промокоды или скидки.
- Для реальных наград потребуется серверный API с проверкой результата и одноразовой выдачей награды.

## Проверка перед публикацией

1. Выполнить `npm ci`.
2. Выполнить `npm run build`.
3. Проверить стартовое меню и 3D-сцену в desktop-браузере.
4. Проверить клавиатуру, паузу, рестарт, столкновения и сбор предметов.
5. Проверить мобильный экран, свайпы и сенсорные кнопки.
6. Проверить production-сборку именно по тому URL-префиксу, где будет размещена игра.
